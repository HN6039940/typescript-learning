# typescript-learning

[vakila/typescript-first-steps](https://github.com/vakila/typescript-first-steps) の演習で直したコードと復習メモを、章ごとに保存するリポジトリです。

## フォルダ構成

| フォルダ | 章の内容 |
| --- | --- |
| `1-javascript/` | JavaScript の弱点と型チェック（checkMe.js） |
| `2-annotations/` | 型注釈の書き方（typeMe.js） |
| `3-compiler/` | コンパイラと tsconfig（compileMe.ts、event-me の Event.js 変換） |
| `4-workflow/` | アプリを TypeScript に移す流れ |
| `5-ecosystem/` | Zod や型テストなどの周辺ツール |

各フォルダには、その章で直したコードをそのまま置きます。
